txt-to-excel

ตัวตรวจไฟล์ export จากเครื่องรูดบัตร ETWIN — วางข้อความลงไป แล้วมันจะบอกว่าเครื่องไหนกำลังมีปัญหา ไม่ใช่แค่บอกว่าไฟล์มี error

หน้านี้เป็นตัวอย่างให้ลองเล่น ตรรกะการตรวจสอบพอร์ตมาจาก txt_to_excel.py ตัวจริงทั้งหมด ประมวลผลในเบราว์เซอร์ล้วน ไม่มีการอัปโหลดข้อมูลไปที่ใด ตัวจริงเป็นโปรแกรม Python ที่เขียนไฟล์ Excel ระบายสีออกมา ส่วนหน้านี้แสดงผลเป็นตารางแทน ข้อมูลตัวอย่างเป็นข้อมูลสังเคราะห์ ไม่ใช่ข้อมูลการรูดบัตรของใครจริง

ข้อมูลนำเข้า

1 บรรทัด = 20 ตัวอักษร · เครื่อง(2) ปี(4) เดือน(2) วัน(2) เวลา(4) EN(6)
ตรวจสองชั้น — กฎตายตัวจับค่าที่เป็นไปไม่ได้ (แดง) · ความถี่รายเครื่องจับค่าที่ถูกต้องแต่ผิดปกติสำหรับเครื่องนั้น (เหลือง)
ความถี่ใช้กับ ปี/เดือน/วัน เท่านั้น — เวลาและ EN มีค่าไม่ซ้ำกันเกือบทุกแถว ถ้าเอาไปจับด้วยจะเตือนทุกบรรทัดจนกลบของจริง
